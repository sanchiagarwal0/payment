Payment Gateway System (Java OOP Project)
Project Description.......

The Payment Gateway System is a simple Java console-based application developed to demonstrate core Object-Oriented Programming (OOP) concepts such as Interface, Abstraction, Polymorphism, and Method Overriding.

The program allows users to:

Choose a payment method (UPI or Credit Card)

Enter the payment amount

Process the transaction

Generate a formatted payment receipt with date and time

This project simulates a basic real-world payment processing system.

🚀 Features:

💰 Accepts payment amount from user

💳 Supports multiple payment modes:

UPI Payment

Credit Card Payment

🧾 Automatically generates payment receipt

📅 Displays current date and time

🔄 Easy to extend with new payment methods

🛠️ Technologies Used :

Java

OOP Concepts

java.util package

Scanner (for user input)

Date (for current date & time)
